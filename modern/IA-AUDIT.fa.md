# ممیزی معماری اطلاعات — ۴ نوامبر ۲۰۲۶

دامنهٔ اجرا: `modern/`، نسخهٔ فعلی Next.js 16.4.2 / React 19.3.1، App Router، خروجی استاتیک، TypeScript، GSAP و MDX محلی. نسخهٔ قدیمی `../dist` و تمام تغییرات قبلی آن حفظ می‌شوند. پیش از شروع، کل `modern/` در Git ثبت‌نشده بود؛ فایل‌های QA، README، اسکریپت‌ها و خروجی‌های قدیمی نیز تغییرات قبلی داشتند. هیچ reset، commit، push یا deploy انجام نمی‌شود.

|---|---|---|---|
| خانه `/` | موجود | ترتیب: Hero، معرفی متحرک، سوابق، تخصص، گالری خالی، پژوهش، FAQ، تماس؛ گالری دیر دیده می‌شود | اصلاح ترتیب، حفظ زبان بصری و انیمیشن پزشک |
| منوی مشترک دسکتاپ و موبایل | موجود | درباره، تخصص، پژوهش، تماس؛ خانه، گالری و راهنمای بیماران ندارد | اصلاح با یک منبع مشترک و CTA تماس |

| پژوهش‌ها `/publications/` | موجود | سه پژوهش مستند با فیلتر، جست‌وجو و پیوند ناشر | حفظ کامل؛ دسترسی از مقالات |

| تماس `/contact/` | موجود | تلفن، نشانی، جست‌وجوی نقشه و نظام پزشکی دارد؛ ساعات واقعی نامعلوم | حفظ اطلاعات، بیان نیاز به هماهنگی ساعات |

| SEO و دسترس‌پذیری | موجود | metadata، schema، RTL، کیبورد منو و sitemap برای پنج مسیر؛ لینک‌های جدید باید بررسی شوند | گسترش به مسیرهای عمومی جدید، حفظ noindex تا تعیین دامنه |

این ممیزی بر بررسی عملکرد کد، مدل محتوا، مسیرها و آزمون‌های موجود استوار است. اطلاعات درمانی و رزومهٔ جدید از بیرون اضافه نمی‌شود. تصاویر موجود پزشک در اسناد پروژه نمایشی توصیف شده‌اند و تصویر نمونه‌جراحی محسوب نمی‌شوند.
