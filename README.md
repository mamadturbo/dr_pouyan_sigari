# وب‌سایت دکتر پویان سیگاری

نسخهٔ اصلی و قابل توسعهٔ سایت در پوشهٔ **modern/** قرار دارد: Next.js، React، TypeScript، محتوای فارسی و راست‌به‌چپ، صفحات خدمات و مقالات، گالری، تست‌ها و خروجی استاتیک.

## راه‌اندازی نسخهٔ اصلی

نیازمندی‌ها: Node.js 24.15 یا جدیدتر و pnpm 11.25.0.

```sh
cd modern
pnpm install --frozen-lockfile
pnpm dev
```

```sh
pnpm typecheck
pnpm test
pnpm build
pnpm preview
```

راهنمای کامل اجرا و پیش‌نمایش ویندوز در [modern/README.md](modern/README.md)، راهنمای انتشار در [docs/deployment.md](docs/deployment.md) و مستندات معماری در [docs/architecture.md](docs/architecture.md) موجود است.

## ساختار مخزن

- `modern/`: سورس اصلی، محتوای سایت، فایل‌های عمومی و تست‌ها.
- `dist/`: نسخهٔ قدیمی مستقل سایت و دارایی‌های آن.
- `docs/`: مستندات معماری، محتوا، انتشار و بررسی‌ها.
- `research/`: منابع و گزارش‌های بررسی محتوای حرفه‌ای پزشک.
- `scripts/` و `tests/`: ابزارها و تست‌های نسخهٔ قدیمی.

فایل‌های محیطی، وابستگی‌های نصب‌شده و خروجی‌های موقت در Git ثبت نمی‌شوند. ایجاد این مخزن به معنای انتشار سایت روی هاست نیست.

## مستندات نسخهٔ قدیمی

# دکتر پویان سیگاری

لندینگ‌پیج فارسی با چرخش کامل و خودکار پزشک پس از یک فرمان اسکرول.

## وضعیت تحویل

ساخت و بررسی مرورگری نسخهٔ محلی انجام شده است. انتشار قبلی به‌علت قطع اتصال متوقف شده بود؛ در بررسی ۱۹ اکتبر ۲۰۲۶ سرویس Sites برای شناسهٔ ثبت‌شده پاسخ «پروژه پیدا نشد» داد و انتشار ممکن نشد. شناسهٔ قبلی در `.openai/hosting.json` حفظ شده و سایت دیگری ایجاد نشده است. هیچ رمز یا اعتبارنامه‌ای در فایل‌ها ذخیره نشده است.

اشکال اجرا با دوبار کلیک روی `dist/index.html` برطرف شده است: فایل‌های `content.js` و `site.js` اکنون اسکریپت‌های کلاسیک با ترتیب بارگذاری مشخص هستند و به ماژول، `import` یا درخواست `fetch` نیاز ندارند. پوشهٔ `assets` و فایل‌های CSS و JavaScript باید کنار این فایل حفظ شوند.

فایل `dr-sigari-preview.html` در پوشهٔ بالاتر و فایل `preview.html` در ZIP، نسخهٔ تک‌فایلی هستند: فونت، تصاویر، ویدئوی اصلی، CSS و کتابخانه‌ها داخل همان HTML قرار دارند. این پیش‌نمایش را می‌توان مستقل از بقیهٔ فایل‌ها جابه‌جا کرد. آزمون‌های مرورگری در `QA.md` روی نسخهٔ اصلی و همین خروجی تک‌فایلی از طریق HTTP انجام شده‌اند؛ ابزار آزمون مرورگر اجازهٔ باز کردن نشانی `file://` را نمی‌دهد.

## اجرا

برای دیدن سایت، `dist/index.html` یا پیش‌نمایش تک‌فایلی را باز کنید. برای اجرای اختیاری با سرور محلی، با Python 3 از پوشهٔ پروژه اجرا کنید:

```sh
python -m http.server 4173 --directory dist
```

سپس http://localhost:4173 را باز کنید.

## ویرایش

- `dist/content.js`: سوابق، خدمات، پژوهش‌ها، پرسش‌ها و اطلاعات تماس.
- `dist/index.html`: ساختار صفحه و متن معرفی.
- `dist/styles.css`: ظاهر و چیدمان واکنش‌گرا.
- `dist/site.js`: تعاملات، Lenis و روایت اسکرولی.
- `dist/story-player.js`: چرخهٔ آماده‌سازی، پخش کامل و آزاد کردن قفل اسکرول.
- `dist/assets/doctor-turn-flow.mp4`: ویدئوی پیوستهٔ رفت‌وبرگشت با سرعت ۶۰ فریم در ثانیه؛ هر جهت حدود ۰٫۷۷ ثانیه. فایل در آغاز بارگذاری می‌شود و بین حرکت‌ها با عکس تعویض نمی‌شود.
- `scripts/package.py`: ساخت دوبارهٔ پیش‌نمایش تک‌فایلی و ZIP از آخرین سورس.

صحنهٔ پزشک صفحه را تا پایان بخش متناظر ویدئو قفل نگه می‌دارد. برگشت با اسکرول رو به بالا بخش دوم همان ویدئو را پخش می‌کند؛ بارگذاری و تعویض منبع در بین چرخش‌ها رخ نمی‌دهد. متن با پیشرفت واقعی ویدئو، با نمایش تدریجی سطرها و حرکت کوتاه جابه‌جا می‌شود. Lenis اسکرول دسکتاپ را نرم می‌کند و ورودی‌های اضافهٔ زمان پخش دوباره صحنه را راه‌اندازی نمی‌کنند.

پس از هر ویرایش، برای به‌روز شدن خروجی‌های قابل‌تحویل اجرا کنید:

```sh
python scripts/package.py
python scripts/check.py
```

با رسیدن به صحنه، صفحه ثابت می‌شود و پزشک در حالت لباس رسمی می‌ماند. یک اسکرول بعدی، یک سوایپ تازه یا کلید پایین/Space، یک چرخش را اجرا می‌کند. حرکت بیشتر چرخ موس، پخش را جلو نمی‌برد یا از ابتدا شروع نمی‌کند. در پایان هر جهت، ویدئو روی حالت نهایی می‌ماند و صفحه آزاد می‌شود. در پنجره‌های کوتاه، محل توقف روی خود تصویر تنظیم می‌شود تا پزشک کامل دیده شود؛ متن‌های اطراف در جریان عادی صفحه باقی می‌مانند.

برای خروج پیش از پخش، اسکرول رو به بالا و برای لغو پخش، کلید Escape در دسترس است. لینک‌های منو نیز قفل را آزاد می‌کنند. خطای پخش یا توقف بارگذاری حداکثر پس از ۸ ثانیه صفحه را آزاد می‌کند. حالت کاهش حرکت، همان دو تصویر ثابت را نمایش می‌دهد.

عکس ابتدای صفحه از فایل `ChatGPT Image Oct 16, 2026, 01_15_57 PM.png` و ویدئوی چرخش از فایل MP4 پیوست کاربر تهیه شده‌اند. فایل‌های اصلی خارج از این پوشه حفظ شده‌اند. توالی تصاویر نسخهٔ قدیمی دیگر در پخش صحنه استفاده نمی‌شود.

کتابخانه‌های محلی: GSAP و ScrollTrigger نسخهٔ 3.15.0، Lenis نسخهٔ 1.3.27 و فونت Vazirmatn نسخهٔ 33.003. فایل مجوز فونت در کنار آن موجود است. هدر فایل‌های کتابخانه شامل ارجاع مجوزهای آن‌هاست.

نوبت‌دهی از طریق تماس با مطب است. این سایت اطلاعات بیمار ذخیره نمی‌کند و برای اجرا به اتصال به پایگاه داده نیاز ندارد. اطلاعات خدمات، نظام پزشکی و تماس بر اساس تأیید کاربر درج شده‌اند؛ سوابق دانشگاهی تاریخی با تاریخ بیان شده‌اند.

## بررسی نسخه‌های جایگزین

```sh
python scripts/preview.py
```

سرور آزمون در پورت 4174 در دسترس است. مسیرهای `/qa/reduced-motion/`، `/qa/video-fail/` و `/qa/slow-video/` به‌ترتیب رفتار برنامه در حالت کاهش حرکت، خطای دریافت ویدئو و دریافت کند آن را آزمایش می‌کنند. شبیه‌سازی کاهش حرکت در این سرور فقط پاسخ `matchMedia` را برای برنامه تغییر می‌دهد؛ تنظیم سیستم‌عامل را تغییر نمی‌دهد. این مسیرها در خروجی انتشار وجود ندارند.

آزمون‌های چرخهٔ پخش و آزاد شدن قفل:

```sh
node --test tests/story-player.test.cjs
```
