# دکتر پویان سیگاری

لندینگ‌پیج فارسی با انیمیشن تعویض لباس وابسته به اسکرول.

## اجرا

با Python 3 از پوشهٔ پروژه اجرا کنید:

```sh
python -m http.server 4173 --directory dist
```

سپس http://localhost:4173 را باز کنید. باز کردن مستقیم فایل HTML به‌دلیل استفاده از ماژول‌های جاوااسکریپت مناسب نیست.

## ویرایش

- `dist/content.js`: سوابق، خدمات، پژوهش‌ها، پرسش‌ها و اطلاعات تماس.
- `dist/index.html`: ساختار صفحه و متن معرفی.
- `dist/styles.css`: ظاهر و چیدمان واکنش‌گرا.
- `dist/site.js`: تعاملات، Lenis و روایت اسکرولی.
- `dist/assets/frames`: ۵۷ فریم از ویدئوی اصلی، به ترتیب بدون تغییر حرکت.

عکس ابتدای صفحه از فایل `ChatGPT Image Oct 16, 2026, 01_15_57 PM.png` و فریم‌ها از ویدئوی پیوست کاربر تهیه شده‌اند. فایل‌های اصلی خارج از این پوشه حفظ شده‌اند.

کتابخانه‌های محلی: GSAP و ScrollTrigger نسخهٔ 3.15.0، Lenis نسخهٔ 1.3.27 و فونت Vazirmatn نسخهٔ 33.003. فایل مجوز فونت در کنار آن موجود است. هدر فایل‌های کتابخانه شامل ارجاع مجوزهای آن‌هاست.

نوبت‌دهی از طریق تماس با مطب است. این سایت اطلاعات بیمار ذخیره نمی‌کند و برای اجرا به اتصال به پایگاه داده نیاز ندارد. اطلاعات خدمات، نظام پزشکی و تماس بر اساس تأیید کاربر درج شده‌اند؛ سوابق دانشگاهی تاریخی با تاریخ بیان شده‌اند.

## بررسی نسخه‌های جایگزین

```sh
python scripts/preview.py
```

سرور آزمون در پورت 4174 در دسترس است. مسیرهای `/qa/reduced-motion/`، `/qa/frames-fail/` و `/qa/slow-frames/` به‌ترتیب رفتار برنامه در حالت کاهش حرکت، خطای دریافت فریم‌ها و دریافت کند فریم‌ها را آزمایش می‌کنند. شبیه‌سازی کاهش حرکت در این سرور فقط پاسخ `matchMedia` را برای برنامه تغییر می‌دهد؛ تنظیم سیستم‌عامل را تغییر نمی‌دهد. این مسیرها در خروجی انتشار وجود ندارند.
